## 🎯 Что мы уже сделали

### 🎬 ComfyUI на 2× Tesla T4 — полностью бесплатно

Запускаем генерацию видео и изображений на двух Tesla T4 (15 GB VRAM каждая) через Kaggle FreeGPU. Никаких облачных подписок, никаких лимитов — только твои идеи.

**Поддерживаемые модели:**

| Модель | Тип | Статус |
|--------|-----|--------|
| **Flux2 GGUF** | Изображения (text-to-image) | 🟢 Работает |
| **LTX 2.3 Video** | Видео (text-to-video, 8 сек 720p) | 🟢 Работает |
| **LTX Director V2** | Видео с управлением (multi-segment) | 🟢 Работает |
| **TTS** | Озвучка текста | 🟢 Работает |

### 🧩 Авторские разработки

- **ComfyUI-LTX2-MultiGPU** — гибридный загрузчик для распределения LTX 2.3 на две T4
- **SageAttention SM75** — форк SageAttention с поддержкой архитектуры Turing (T4)
- **launcher.py** — оркестратор: keep-alive, Cloudflare-туннель, авто-обновление нод
- **Готовые workflow** — LTX Director V2, инъекция SageAttention, авто-установка

### 🤖 Hermes Desktop

AI-ассистент для Windows с собственным ядром. Работает с файлами, памятью, запускает агентов. Не просто чат — реальный помощник.
